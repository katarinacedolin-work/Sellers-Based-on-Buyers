# Campus Connect Prototype

A front-end-only, no-backend prototype of the Campus Connect student marketplace.

## Run it

From this directory, run any static server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## What is implemented

- Home discovery with Book/Shop mental models
- Search and category filtering
- Service listing detail with availability selection
- Product listing detail with quantity controls
- Demo checkout and confirmation states
- Seller profiles and shareable storefront behavior
- Seller stores (a seller can run several): a Stores directory with filters and following, branded store pages with collections, in-store search and Shop/Reviews/About tabs, plus "Sold by" store links on listings, store results in search and a Campus stores shelf on Home
- Inbox with conversation switching and local message sending
- You page with activity and seller tools
- Demo seller onboarding and listing creation
- Notifications, support, report and verification dialogs
- Responsive desktop and mobile navigation

All content is local demo data. No backend, payment processor, database, authentication provider, external images or integrations are connected.
